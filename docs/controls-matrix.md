# Regulatory & AI Governance Controls Matrix (PCI-DSS, HIPAA, GDPR, ISO 27001, NIST AI RMF, ISO 42001, EU AI Act)

| Standard / Section | Regulatory Requirement | Terraform Landing Zone Implementation | Component / File Reference |
| :--- | :--- | :--- | :--- |
| **PCI-DSS v4.0 (Req 1.2)** | Restrict inbound/outbound traffic to only necessary ports | Shared VPC with default `deny_all_egress`, Private Service Connect (PSC) for Google APIs, Cloud NAT for egress, and IAP bastions | `foundation/06-networking/main.tf` |
| **PCI-DSS v4.0 (Req 3.4)** | Protect cardholder data with strong cryptography | Cloud KMS CMEK with 90-day rotation; `custom.requireBigQueryCmek` and Agent Platform CMEK CEL constraints | `foundation/03-custom-constraints/main.tf`, `environments/stg/main.tf`, `environments/prod/main.tf` |
| **NIST AI RMF / ISO 42001 (Manage 2.2)** | Prevent AI Data Exfiltration across training, inference, and RAG pipelines | VPC Service Controls perimeter (`sp_regulated_data_shield`) restricting `aiplatform.googleapis.com` & GCS; CEL custom constraints forcing private VPCs | `foundation/03-custom-constraints/constraints/`, `foundation/06-networking/main.tf`, `docs/ai-governance.md` |
| **GDPR (Art. 32 & 44) / EU AI Act (Art. 10)** | Ensure EU Data Residency and Sovereignty within European regions (`europe-*`) | `gcp.resourceLocations` Org Policy restricting deployments strictly to `in:eu-locations`; EU-regionalized KMS KeyRings, Artifact Registry, and GCS data lakes | `foundation/02-org-policies/main.tf`, `foundation/07-ai-governance/main.tf`, `docs/ai-governance.md` |
| **OWASP LLM01 / NIST AI RMF (Measure 2.6)** | Mitigate Prompt Injection attacks & unauthorized agent tool invocation | Dedicated `sa-agent-serving` with minimal read-only permissions; Private Service Connect isolation; absence of IAM escalation rights | `foundation/04-iam/main.tf`, `foundation/06-networking/main.tf`, `docs/ai-governance.md` |
| **ISO 42001 (A.8.2) / NIST AI RMF (Gov 1.2)** | Model Access Control, Separation of Duties (SoD), and Artifact Integrity | IAM conditional bindings with CEL for Data Scientists, Agent Deployers, and AI Auditors; Workbench guardrails; CMEK Artifact Registry | `foundation/02-org-policies/main.tf`, `foundation/04-iam/main.tf`, `foundation/07-ai-governance/main.tf` |
| **NIST AI RMF / ISO 42001 (Gov 1.1)** | Enterprise AI template project governance with CMEK, isolated data lake and VPC-SC enrollment | Standardized AI template with Cloud KMS CMEK, protected GCS bucket, Vertex AI resources, and perimeter registration | `foundation/07-ai-governance/main.tf` |
| **PCI-DSS v4.0 (Req 10.2) / ISO 42001 / EU AI Act (Art. 12)** | Implement automated audit trails for all system components and AI services data access | Centralized Log Sink to BigQuery with `DATA_READ` / `DATA_WRITE` / `ADMIN_READ` for Vertex AI (`aiplatform.googleapis.com`), BigQuery, and Storage | `foundation/05-logging/main.tf`, `modules/log-sink` |
| **HIPAA (§ 164.312(a))** | Implement access controls allowing only authorized personnel | IAM Conditional Bindings with CEL restrictions based on user role and schedule | `foundation/04-iam/main.tf`, `modules/iam-conditional-binding` |
| **HIPAA (§ 164.312(e)) / ISO 27001** | Implement guardrails against unauthorized data exfiltration and transmission | Reusable VPC Service Controls perimeter module (`modules/vpc-sc-perimeter`) restricting all supported GCP/AI APIs, with exceptions via Access Levels and Ingress Policies | `modules/vpc-sc-perimeter/`, `foundation/06-networking/main.tf`, `environments/dev/main.tf`, `environments/stg/main.tf`, `environments/prod/main.tf` |
| **ISO 27001 (A.12.6) / PCI-DSS v4.0 (Req 11.5)** | Centralized threat detection, vulnerability monitoring, and posture management | Security Command Center (SCC) organization-level streaming notifications for active HIGH/CRITICAL findings with noise suppression mute rules | `foundation/00-organization/main.tf` |
| **SOC 2 (CC6.1) / ISO 27001 (A.15.1) / GDPR (Art. 28)** | Cloud provider access oversight, approval workflows, and immutable staff audit logging | Access Approval enforced across all services with notification routing and Access Transparency logs captured in central immutable BigQuery sink | `foundation/00-organization/main.tf`, `foundation/05-logging/main.tf` |
| **ISO 27001 (A.9.2.3)** | Management of privileged access rights | Keyless WIF, disabled static SA keys, time-bound emergency break-glass IAM | `bootstrap/main.tf`, `foundation/04-iam/main.tf` |
